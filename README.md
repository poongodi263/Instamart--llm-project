# Instamart LLM Project

An LLM-powered project inspired by Instamart, designed to make grocery shopping easier through natural-language assistance.

## Project status

This project is at the planning stage. The initial goal is to build an assistant that can help users discover products, find relevant items, and get shopping recommendations.

## Planned capabilities

- Understand grocery-related questions in natural language
- Help users search for and discover products
- Provide relevant suggestions and recommendations
- Support a simple, user-friendly interface
